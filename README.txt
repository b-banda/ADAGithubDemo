ADA Final Project
Project Title: "Association Between Housing Instability and Non-Specific Psychological Distress in NYC During 2020"

Project Description
This project investigates the association between housing instability and non-specific psychological distress among adults in New York City using the 2020 NYC Community Health Survey. The analysis applies logistic regression models to explore key predictors, including age, income, employment, and health insurance status, while adjusting for potential confounders.

Files in Repository
1. ADA-Final_Project.Rmd

Main R Markdown file containing all steps of the analysis, including data cleaning, exploratory analysis, logistic regression modeling, and visualizations.
Generates HTML and PDF outputs summarizing the results.

2. chs2020_public.sas7bdat

Raw dataset from the 2020 NYC Community Health Survey. This file is publicly available from the NYC Department of Health and Mental Hygiene.


3. Banda Bernard ADA Final Project.pptx

PowerPoint presentation summarizing the project for a class or professional audience.
